RECEPCIÓN AUTOMÁTICA DE DTE POR CORREO
- Crear en Supabase Edge Function Secrets un secreto fuerte llamado:
  SII_DTE_INBOUND_SECRET
- Configurar la casilla de intercambio DTE/servicio de correo entrante para reenviar el mensaje
  a la Edge Function facturacion-sii mediante webhook.
- El webhook usa action=exchange_email_ingest y debe enviar el secreto en el header
  x-ale-dte-secret. Acepta raw_mime, xml o attachment_base64.
- No escribas el valor real del secreto en HTML, JavaScript público ni GitHub.

SI VIENES DE UNA VERSIÓN ANTERIOR
Ejecuta, en orden, los SQL que aún no hayas aplicado dentro de INSTALACION_SUPABASE.
Para Facturación SII, aplica también en orden los SQL de INSTALACION_SUPABASE_SII que falten.

IMPORTANTE
- Las acciones ACD/ERM/RCD/RFP/RFT tienen efectos tributarios y deben registrarse sólo cuando correspondan.
- Mantén SII_MASTER_KEY y los demás secretos únicamente en Supabase/servidor.
- La postulación, Set de Pruebas, simulación, muestras, declaración de cumplimiento y autorización final
  continúan dependiendo del proceso oficial del SII; este ZIP no significa que el SII ya haya certificado el software.
